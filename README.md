# 什么是电 · 3D 电学科普

用可交互的 3D 模型（Three.js）讲清楚电的一切：从原子里的电子，到电路、电磁、发电机，再到电磁波、无线电和电话。每一章都是一个可以旋转、缩放、调参数的 3D 场景，旁边配有原理讲解、核心公式、实时读数和曲线图。

## 内容（23 章）

| 板块 | 章节 |
| --- | --- |
| 电荷与电场 | 原子与电荷 · 摩擦起电与静电感应 · 库仑定律 · 电场与电场线 · 电势与电压 |
| 电路 | 电流 · 电阻 · 欧姆定律 · 串联与并联 · 电功率与焦耳热 · 电池 · 电容器 · 半导体与二极管 |
| 电与磁 | 电流的磁场 · 电动机 · 电磁感应 · 发电机与交流电 · 变压器与输电 |
| 电磁波与通信 | 电磁波 · 电磁波谱 · 天线：发射与接收 · 无线电广播 · 电话 |

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生成静态站点到 dist/
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。

## 结构

```
src/
  main.js          页面框架、路由（#/c/<章节id>）、首页
  engine.js        渲染器、相机、辉光后期、章节加载/卸载
  ui.js            右侧面板控件：滑块、分段、开关、读数、示波器、坐标图
  chapters.js      章节注册表（顺序即学习路线）
  lib/kit.js       共用 3D 积木：粒子、箭头、导线、电子流、电池、电阻、灯泡、电表、磁铁、线圈、场线……
  scenes/*.js      每章一个文件，写法见 scenes/_TEMPLATE.md
```

## 操作

- 拖动旋转、滚轮缩放、右键平移
- 视口下方：暂停/播放（空格）、慢放 0.25× ~ 2×、重置、全屏
- `Alt + ←/→` 切换上一章 / 下一章

所有模型都是示意图：原子核、电子等尺度经过放大，电子运动经过加速或减速，以便观察。
